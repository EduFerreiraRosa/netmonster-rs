# Auditoria dos dados iniciais

Data: 23/11/2026. Resultado: **nenhuma célula elegível para publicação**.

O histórico disponibilizado afirma que o usuário marcou pontos manualmente. As imagens de mapa não fornecem uma associação completa e confiável entre identificadores de célula e coordenadas exatas da infraestrutura.

Um export JSON fornecido no histórico foi examinado localmente, sem ser copiado para este repositório. Ele contém 302 registros: 298 sem par de coordenadas geográficas válido e quatro com coordenadas e descrições. Os quatro não possuem procedência suficiente para distinguir torre confirmada de posição de recepção/estimativa. Foram excluídos; nenhum endereço ou coordenada desses registros foi reproduzido aqui.

Identificadores mencionados em respostas anteriores não foram tratados como fonte primária, nem associados a coordenadas por inferência. As sentinelas de desconhecido não foram convertidas em localizações.

Para a primeira contribuição útil, fornecer um export sanitizado das células escolhidas e confirmar, para cada uma, que a coordenada é da torre identificada. A evidência deve também vincular a identidade rádio à infraestrutura. Não é necessário reenviar o log completo.
