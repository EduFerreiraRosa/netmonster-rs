# Atribuição

Base comunitária netmonster-rs — contribuidores identificados no histórico Git e no campo `atribuicao` de cada registro em `metadata/registros.json`. Licença dos dados: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Preserve também referências de fonte e avisos de modificações ao redistribuir.

Nenhum dado de célula publicado na versão inicial. Nenhuma base externa foi incorporada.

Formato de atribuição sugerido após publicação: “Fonte: netmonster-rs e seus contribuidores, CC BY 4.0”, com link para o repositório real e indicação de alterações quando houver. O nome NetMonster identifica o aplicativo de destino e não implica endosso.
